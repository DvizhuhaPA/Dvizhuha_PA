# Движуха · PA-S1 · Продуктовая аналитика

Командный трек А, 4 участника: **Станислав, Андрей, Даниил, Елена**.
Репозиторий: https://github.com/Andre1ka11/Dvizhuha_PA

## Задача

Описать концепцию сервиса поиска мероприятий и покупки билетов, проверить исторические
данные Afisha, зафиксировать определения и метрики, подготовить трекинг, первые расчёты,
этический анализ и критерии успеха. Все девять содержательных разделов PA-S1 находятся
в **[dvizhuha.ipynb](dvizhuha.ipynb)**. Таблицы и графики сохранены в ноутбуке.

## Данные

- Источник: [Afisha Data (Marketing), Ella Nihill, Kaggle](https://www.kaggle.com/datasets/ellanihill/marketing-roi-analysis-costs-orders-visits).
- Зафиксирована **версия 1**, опубликованная 09.10.2022. Метаданные проверены 30.10.2026.
- `visits_log_us.csv`: 359 400 строк; `orders_log_us.csv`: 50 415; `costs_us.csv`: 2 542.
- Основное общее окно: `[2017-06-01; 2018-06-01)`. Один заказ вне окна исключён.
- В `data/manifest.json` находятся версия, ссылка загрузки, размеры и SHA-256 исходных файлов.
- Исходные CSV находятся в `data/raw/` и подготовлены для включения в Git.
- Ноутбук читает их напрямую, без сетевой загрузки, и проверяет контрольные суммы.
- Лицензия Kaggle API: **Unknown**. Первичное происхождение и право распространения
  не подтверждены; включение файлов в проект не заменяет разрешение автора.

## Запуск

Проверено на **Python 3.12.14**, pandas 3.1.0, numpy 2.5.4, matplotlib 3.11.2.
Прямые и транзитивные зависимости зафиксированы в `requirements.txt`.

Команды для **PowerShell из корня репозитория**, если установлен Python 3.12:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## Что получилось

- 20 кодовых ячеек; загрузка, проверки, расчёты и графики разделены на шаги.
  Три рисунка с результатами, таблицы и выводы сохранены в ноутбуке.
- Полных дублей и пропусков нет. Обнаружены 2 сессии с отрицательной длительностью;
  они сохраняются для активности, ошибочная длительность маскируется.
- 01.04.2018 отсутствуют и визиты, и расходы: отсутствие активности и сбой выгрузки неразличимы.
- Средний наблюдаемый DAU: **906**; средние недельные покупатели полных недель: **822**.
- Конверсия в первую покупку за 7 суток: **12,69%** при полном окне наблюдения.
- Взвешенный когортный retention M1: **6,49%** для 11 зрелых когорт.
- По зрелым когортам июня 2017 — февраля 2018 платных каналов:
  LTV90 = **5,72**, CAC90 = **9,48** ден. ед., отношение = **0,604**.
  Это оценка по выручке и месячному бюджету, без маржинальности, прогнозного пожизненного LTV
  и доказанной индивидуальной атрибуции. Каналы 6/7 не имеют расходов и не получают нулевой CAC.
- Определены North Star, две диагностические и риск-метрика, пять событий трекинга,
  полный этический чек-лист и три численные цели со способом проверки.

Конверсия, retention и юнит-экономика используют определения и окна из раздела 3 ноутбука.
Выручка не приравнивается к прибыли. Исторические различия не доказывают причинность.
